# Together Go — แผนการสร้างเว็บ (Full-Stack Project Plan)

เว็บรวมคนแปลกหน้าที่ยืนยันตัวตนแล้ว มาสร้างทริปและเที่ยวด้วยกันแบบเพื่อน รองรับภาษาไทย + อังกฤษ (สลับได้)

## หน้าตาและความรู้สึก (Design System)
- โทนสี: น้ำเงินเข้ม (Trust - #0F294A / #1E3A8A) + เขียวอมฟ้า (Safety/Calm - #0D9488 / #14B8A6) บนพื้นขาวนวล (#F8FAFC / #FFFFFF)
- ตัวอักษรอ่านง่าย รองรับภาษาไทย (เช่น Prompt / Noto Sans Thai) ปุ่มใหญ่ ข้อมูลไม่แน่นเกินไป
- ป้ายสถานะ "ยืนยันตัวตนแล้ว" และ "ผ่านแบบประเมิน" แสดงชัดเจนบนโปรไฟล์ทุกคน

## บทบาทผู้ใช้ (User Roles)
- **Admin:** ทำได้ทุกอย่าง ตั้งค่าค่าธรรมเนียม ดูรายได้ ให้สิทธิ์พนักงาน (Login เริ่มต้น: Username `admin`, Password `1234`)
- **Staff:** ตรวจบัตร/ใบขับขี่ พิจารณาผลประเมิน จองที่พักให้ทริป รับเรื่องฉุกเฉินและรายงาน (ไม่เห็นรายได้ แก้การตั้งค่าไม่ได้)
- **User (นักเดินทาง):** สร้างทริป ขอเข้าร่วม รับหน้าที่ เป็นคนขับ
- **Host (เจ้าของที่พัก):** ลงที่พัก ดูการจอง ดูยอดเงินที่จะได้รับ

## ฟีเจอร์หลัก (Core Features)
1. **สมัครสมาชิกและยืนยันตัวตน:** เข้าสู่ระบบด้วยอีเมล/รหัสผ่าน หรือ Google -> บังคับทำ 4 ขั้นตอนก่อนใช้งาน: (1) ยอมรับ PDPA (ถอนความยินยอม/ขอลบข้อมูลได้), (2) กรอกโปรไฟล์ + ผู้ติดต่อฉุกเฉิน, (3) อัปโหลดบัตรประชาชน + รูปเซลฟี่ถือบัตร, (4) ทำแบบประเมินสุขภาพจิตเบื้องต้น (ระบบคิดคะแนนฝั่ง Backend เท่านั้น, ผ่านเกณฑ์ -> รอแอดมินอนุมัติบัตร, ไม่ผ่าน -> ส่งแอดมินพิจารณา, เก็บประวัติทุกครั้ง, Cooldown 3 วัน, แจ้งชัดว่าไม่ใช่การวินิจฉัยทางการแพทย์)
2. **ทริป:** ค้นหา/กรองตามจังหวัด วันที่ ราคา -> สร้างทริป (เลือกที่พักจากในเว็บ, คำนวณค่าน้ำมันต่อคน = ระยะทาง × ราคาน้ำมัน ÷ จำนวนคน แสดงยอดเท่านั้น จ่ายคนขับกันเอง) -> หน้าทริป (รายละเอียด, สมาชิก, หน้าที่, สรุปค่าใช้จ่าย, ปุ่มขอเข้าร่วม)
3. **การเข้าร่วมและชำระเงิน:** ขอเข้าร่วม -> คนสร้างทริปดูโปรไฟล์และระดับผลประเมิน (ไม่เห็นคำตอบรายข้อ) -> อนุมัติ -> จ่ายผ่านเว็บ (ค่าที่พักหารตามจำนวนคน + ค่าธรรมเนียมคงที่ต่อคน) -> ยกเลิกคืนเฉพาะค่าที่พัก
4. **หน้าที่ในทริป:** ไกด์นำทาง, ดูแลที่พัก, จัดหาเสบียง/ร้านอาหาร, คนขับ (เพิ่ม/ลบได้, กดรับเองหรือมอบหมาย)
5. **ระบบคนขับ:** เฉพาะผู้ที่อัปโหลดใบขับขี่และผ่านการอนุมัติ -> แสดง Rating -> สมาชิกโหวต -> คนสร้างทริปยืนยันเลือกคนสุดท้าย
6. **ระหว่างและหลังทริป:** แชทกลุ่ม Realtime (เฉพาะสมาชิกที่จ่ายเงินแล้ว), ปุ่มแจ้งเหตุฉุกเฉิน (โชว์เบอร์ 191/1669, ส่งพิกัด lat/lng เข้าหลังบ้าน, โชว์เบอร์ผู้ติดต่อฉุกเฉิน), รายงานผู้ใช้, รีวิวและให้คะแนนเพื่อนร่วมทริป + คนขับแยกกัน
7. **เจ้าของที่พัก:** ลงที่พัก (รออนุมัติ), ดูสถานะการจอง (รอจอง -> จองแล้ว -> เข้าพักแล้ว / ยกเลิก), ดูยอดโอนเงิน (รอโอน -> โอนแล้ว พร้อมหลักฐาน), ระบบอีเมลแจ้งเตือน
8. **หลังบ้านแอดมิน/พนักงาน:** ภาพรวม, ตรวจบัตร/ใบขับขี่, พิจารณาผลประเมิน + ประวัติย้อนหลัง, จัดการที่พัก/ทริป/รายงาน/เหตุฉุกเฉิน/คืนเงิน, ตั้งค่าค่าธรรมเนียมและเกณฑ์แบบประเมิน, จัดการพนักงาน

## รายละเอียดทางเทคนิค (Technical Specs)
- **Database Tables:** `profiles`, `emergency_contacts`, `consents`, `user_roles` (admin/staff/host/user + `has_role`), `screening_attempts` (cooldown 3 days server-side), `verification_documents` (private bucket), `accommodations`, `trips`, `trip_roles`, `trip_members` (requested/approved/paid/cancelled), `driver_applications`, `driver_votes`, `ratings`, `messages` (realtime), `reports`, `emergency_alerts` (lat/lng), `bookings`, `host_payouts`, `payments`, `app_settings`
- **Security & Logic:** คะแนนแบบประเมินคำนวณฝั่ง Backend/DB เท่านั้น, บังคับสิทธิ์การเข้าถึงข้อมูล (RLS/Middleware) ตาม Role และสถานะการจ่ายเงิน
- **Routes:** `/`, `/trips/$id`, `/auth`, `/onboarding`, `/trips/new`, `/my-trips`, `/host`, `/admin/*`
- **i18n:** ไฟล์คำแปลไทย/อังกฤษ เก็บภาษาที่เลือกไว้ในเครื่อง (localStorage)

## ลำดับการสร้าง (9 Phases)
- **Phase 1:** ระบบดีไซน์ + สลับภาษา (TH/EN) + ระบบเข้าสู่ระบบ (รวม admin/1234) + Onboarding ยืนยันตัวตน 4 ขั้นตอน และแบบประเมิน
- **Phase 2:** ทริป ค้นหา/กรอง สร้างทริป หน้าที่ในทริป คำนวณค่าเดินทาง
- **Phase 3:** ระบบที่พัก + หน้าจัดการของเจ้าของที่พัก
- **Phase 4:** ระบบขอเข้าร่วม/อนุมัติ + ระบบคนขับ (ใบขับขี่ โหวต Rating)
- **Phase 5:** หลังบ้านแอดมินและพนักงานครบวงจร
- **Phase 6:** แชทกลุ่ม Realtime + ปุ่มแจ้งเหตุฉุกเฉิน (พิกัด + ผู้ติดต่อฉุกเฉิน) + รายงาน + รีวิวหลังทริป
- **Phase 7:** สถานะการจองที่พัก + ระบบบันทึกการโอนเงินเจ้าของที่พัก
- **Phase 8:** ระบบอีเมลแจ้งเตือน (สอบถามโดเมนก่อนตั้งค่า)
- **Phase 9:** ระบบชำระเงินโหมดทดสอบ (เสนอผู้ให้บริการเพื่อยืนยันก่อนเปิดใช้) + Webhook บันทึกสถานะ
